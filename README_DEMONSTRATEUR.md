# Démonstrateur de Fonctions Python 🐍

Un guide complet et progressif pour maîtriser les fonctions Python, de la base aux concepts avancés.

## Description

Ce démonstrateur est conçu pour vous accompagner dans votre apprentissage des fonctions Python. Il couvre 10 niveaux de difficulté croissante avec des exemples pratiques et commentés.

## Contenu du Démonstrateur

### Niveau 1 : Les Bases
- Fonctions simples sans paramètre
- Fonctions avec paramètres
- Utilisation de `return`
- Retour de valeurs multiples

### Niveau 2 : Paramètres Avancés
- Paramètres par défaut
- Arguments nommés (keyword arguments)
- `*args` - Arguments positionnels variables
- `**kwargs` - Arguments nommés variables
- Combinaison de tous les types de paramètres

### Niveau 3 : Fonctions Lambda
- Syntaxe lambda de base
- Lambda avec plusieurs paramètres
- Utilisation avec `map()`, `filter()`, `sorted()`

### Niveau 4 : Portée des Variables
- Variables locales vs globales
- Mot-clé `global`
- Mot-clé `nonlocal`
- Fonctions imbriquées

### Niveau 5 : Fonctions d'Ordre Supérieur
- Fonctions prenant des fonctions en paramètre
- Fonctions retournant des fonctions
- Closures (fermetures)

### Niveau 6 : Décorateurs
- Décorateurs simples
- Décorateurs avec arguments
- Décorateurs paramétrés
- Décorateurs utilitaires (timing, etc.)

### Niveau 7 : Générateurs
- Syntaxe `yield`
- Générateurs Fibonacci
- Expressions génératrices
- Méthode `send()`

### Niveau 8 : Récursivité
- Factorielle récursive
- Fibonacci avec mémoïzation
- Parcours de structures imbriquées

### Niveau 9 : Annotations de Type
- Type hints simples
- Types complexes (`List`, `Dict`, `Tuple`)
- `Optional` et `Union`
- Type `Callable`

### Niveau 10 : Techniques Avancées
- `functools.partial`
- `functools.wraps`
- `functools.lru_cache`
- Décorateurs de classe
- Context managers
- Décorateurs empilés

## Comment Utiliser ce Démonstrateur

### Option 1 : Exécution Complète
```bash
python3 demonstrateur_fonctions_python.py
```

Cette commande exécute tous les exemples et affiche les résultats.

### Option 2 : Lecture et Expérimentation
1. Ouvrez le fichier dans votre éditeur préféré
2. Lisez les commentaires et le code
3. Modifiez les exemples pour expérimenter
4. Exécutez des sections spécifiques dans un REPL Python

### Option 3 : Apprentissage Progressif
1. Commencez par le Niveau 1
2. Exécutez et comprenez chaque exemple
3. Essayez de modifier le code
4. Passez au niveau suivant une fois à l'aise

## Exercices Pratiques

À la fin du démonstrateur, vous trouverez 8 exercices pour mettre en pratique ce que vous avez appris :

1. Comptage d'occurrences avec dictionnaire
2. Décorateur de logging
3. Générateur de nombres premiers
4. Inversion de chaîne récursive
5. Rate limiting avec décorateur
6. Composition de fonctions
7. Générateur de parcours de fichier
8. Méthodes de classe avancées

## Conseils d'Apprentissage

1. **Ne vous précipitez pas** : Prenez le temps de comprendre chaque concept
2. **Expérimentez** : Modifiez les exemples, cassez-les, réparez-les
3. **Pratiquez** : Essayez les exercices proposés
4. **Construisez** : Créez vos propres fonctions en appliquant ce que vous apprenez
5. **Partagez** : Expliquez les concepts à quelqu'un d'autre pour mieux les retenir

## Prérequis

- Python 3.6 ou supérieur (pour les f-strings et annotations de type)
- Connaissances de base de Python (variables, conditions, boucles)
